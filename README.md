# Training Tracker для Obsidian

Трекер тренировок внутри Obsidian. Никаких серверов и подписок: база данных — это обычные
`.md`-заметки в твоём хранилище, которое синхронизируется через iCloud (или что угодно ещё).
Интерфейс сделан по мотивам мобильных трекеров: программы-карточки, экран тренировки
с большими кнопками, таймер отдыха, прогресс по упражнениям.

## Что умеет

- **Программы** (Full Body 1, 2, 3…): упражнения с весом/повторами/временем по каждому подходу,
  цвет, счётчик «выполнено N раз | X кг поднято всего».
- **Тренировка**: таймер, отметка подходов (зелёные строки), кнопка «Записать следующий подход»,
  «ВСЕ», таймер отдыха (−15/+15, звук), «Прошлый раз: 40 кг × 20…», добавление/замена/перестановка
  упражнений на ходу. Прогресс сохраняется в заметку каждую секунду, так что если iOS выгрузит
  Obsidian — ничего не пропадёт.
- **После тренировки** можно одним переключателем обновить программу новыми весами.
- **Упражнения**: ~870 упражнений из открытой базы с картинками, техникой, мышцами; русские названия,
  поиск на русском и английском, фильтр по мышцам. **Свои упражнения — бесплатно и без ограничений**:
  название, тип учёта, мышцы, картинки/GIF из хранилища или по ссылке.
- **Отчёт**: тренировки и тоннаж по неделям, история; у каждого упражнения — рекорды,
  расчётный 1ПМ и график прогресса.

## Установка

Плагин не из каталога, поэтому ставится одним из способов:

**Через BRAT (удобно на iPhone).** Установи из каталога плагин *BRAT* → «Add beta plugin» →
`tyrandel-0/obsidian-training-extension`. Нужен опубликованный релиз (см. «Релиз» ниже).

**Вручную.** Скопируй `main.js`, `manifest.json`, `styles.css` в
`<хранилище>/.obsidian/plugins/training-tracker/` и включи плагин в настройках → «Сторонние плагины».
Раз папка `.obsidian` лежит в хранилище, iCloud сам донесёт плагин до телефона — достаточно
сделать это один раз на компьютере.

Открыть: иконка гантели на боковой панели или команда «Training Tracker: Открыть трекер».
При первом запуске во вкладке «Упражнения» нажми «Загрузить базу».

## Где лежат данные

```
Training/
  Routines/Full Body 1.md          программы
  Workouts/2026/2026-09-27 19-13 Full Body 1.md
  Exercises/Мой жим.md             свои упражнения и правки упражнений из базы
  Exercises/media/…                картинки, скачанные по ссылке
  .library/exercises.json          база упражнений
  .library/images/…                кэш картинок (скачиваются при первом просмотре)
```

Папку можно сменить в настройках плагина → «Папка с данными» (подойдёт и вложенная, например
`Data/Training`) → «Применить». Если данные уже есть в старой папке, плагин предложит перенести их.

Тренировка — обычная заметка: сверху свойства (дата, длительность, тоннаж, список упражнений —
удобно для Dataview/Bases), ниже блок ` ```training-workout ` с подходами в YAML. В режиме чтения
плагин показывает его таблицей. Файлы можно править руками — трекер подхватит изменения.

Своё упражнение — заметка в `Training/Exercises/`:

```markdown
---
name: Жим лёжа · гантели
muscles: [chest, triceps]
equipment: dumbbell
track: weight_reps        # weight_reps | reps | time | distance_time
images: ["[[bench.gif]]"]
---
1. Лечь на скамью, гантели над грудью.
2. Опустить до уровня груди и выжать.
```

Если добавить `id:` упражнения из базы (например `id: Dumbbell_Bench_Press`), заметка
**перекроет** его: так можно переименовать упражнение или подменить картинки на свою GIF.

## Про базу упражнений и картинки

По умолчанию используется [free-exercise-db](https://github.com/yuhonas/free-exercise-db):
876 упражнений, лицензия Unlicense (общественное достояние). У каждого упражнения два фото
(начальное и конечное положение); на экране упражнения они чередуются, получается анимация.
Русские названия переведены и лежат в `src/data/ru-names.json`.

Красивые 3D-GIF с подсвеченными мышцами, как в коммерческих приложениях, — это платные базы
(ExerciseDB, Gymvisual и т.п.), свободно их взять нельзя. Зато к любому упражнению можно
прикрепить любую GIF: «Изменить» → «Картинки / GIF» → из хранилища или по ссылке.

В настройках можно:
- скачать все картинки заранее (~95 МБ), чтобы в зале без интернета всё работало;
- подставить свою базу в том же JSON-формате (адрес базы и префикс картинок).

## Разработка

```bash
npm install
npm run dev       # сборка main.js в режиме watch
npm run preview   # UI в браузере на http://localhost:8000 с демо-данными (без Obsidian)
npm test          # юнит-тесты сериализации и статистики
npm run build     # typecheck + production-сборка
```

Для предпросмотра положи рядом базу и (по желанию) картинки:
`dev/www/exercises.json` (скачай из free-exercise-db); без параметров картинки грузятся
прямо с GitHub. Экран телефона удобно смотреть через devtools → device toolbar.

Код: `src/format.ts` — формат заметок и статистика (без зависимостей от Obsidian, покрыт тестами),
`src/store.ts` — синхронизация с хранилищем, `src/library.ts` — база и кэш картинок,
`src/ui/*` — интерфейс на Preact.

### Релиз

Подними версию в `manifest.json`, `package.json` и `versions.json`, затем
`git tag 0.1.1 && git push origin 0.1.1` (или Actions → Release → Run workflow) — GitHub Actions соберёт и опубликует релиз.
